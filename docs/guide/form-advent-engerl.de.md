# Advent-Engerl online auslosen

Über den Advent steckt jedes Engerl seinem Bengerl heimlich kleine Freuden zu, etwa einmal pro Woche: eine Kleinigkeit, ein Zettel, eine gute Tat. Aufgelöst wird bei der Feier.

[Mit dieser Vorlage starten](app:?vorlage=advent-engerl)

## So geht’s mit SecretEngerl

1. [Vorlage „Advent-Engerl“ öffnen](app:?vorlage=advent-engerl).
2. Die Namen eintragen, einen pro Zeile. Eine Leerzeile trennt Gruppen, die sich nicht ziehen sollen.
3. Den Tag der Auflösung, ein kleines Budget pro Woche und auf Wunsch ein Motto pro Adventwoche eintragen, dann auf „Ziehen“ tippen.
4. Jedem Engerl sein Los als Link im Einzelchat schicken.

## Was eingestellt ist

- Jedes Los nennt die Mottos der vier Adventwochen, falls gesetzt.
- „In den Kalender“ legt einen Termin pro Adventsonntag und einen für die Auflösung an, ohne den Namen des Bengerls.
- Wer in derselben Gruppe ist, zieht sich nicht, und niemand beschenkt sich gegenseitig.
