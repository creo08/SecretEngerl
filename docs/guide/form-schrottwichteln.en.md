# Draw Schrottwichteln online

Buy nothing. Everyone gives something they already own and no longer need: leftovers, bad buys, kitsch. Funny yes, broken or gross no.

[Start with this template](app:?vorlage=schrottwichteln)

## How it works with SecretEngerl

1. [Open the template "Schrottwichteln"](app:?vorlage=schrottwichteln).
2. Enter the names, one per line. A blank line separates groups who should not draw each other.
3. Enter the exchange date and tap "Draw". There is no budget.
4. Send every Engerl their draw as a link in a one-to-one chat.

## What is set

- There is no budget.
- Every draw carries the rule "Buy nothing, only what you already have".
- People in the same group do not draw each other, and there are no mutual pairs.
- A theme is optional.
