# Schrottwichteln

Buy nothing. Everyone gives something they already own and no longer need: leftovers, bad buys, kitsch. Funny yes, broken or gross no.

[Start with this template](app:?vorlage=schrottwichteln)

## What is set

- There is no budget.
- Every draw carries the rule "Buy nothing, only what you already have".
- People in the same group do not draw each other, and there are no mutual pairs.
- A theme is optional.
